# Sichen Tao — Academic Homepage Next

Public preview of Sichen Tao's redesigned academic homepage.

## Live site

<https://sichentao.github.io/academic-homepage-next/>

## Information architecture

- About
- News
- Publications
- Services
- Awards
- Contact

The site uses the open-source [al-folio](https://github.com/alshedivat/al-folio) academic theme as a maintained runtime. The visual direction borrows the restrained information architecture of Ran Cheng's academic homepage while using Sichen Tao's own identity, verified profile data, research record, and Tohoku University purple accent.

## Local build

```bash
bundle install
bundle exec jekyll serve --baseurl /academic-homepage-next
```

## Content policy

Public pages include published and accepted work. Submitted and under-review manuscripts remain in structured source data and are excluded from the public publication list.
